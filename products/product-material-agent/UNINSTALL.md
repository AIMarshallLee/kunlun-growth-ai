# 卸载与回滚

## 卸载

1. 确认要删除的目录名称正是 `product-material-agent`。
2. 如需保留本地配置，先把 `config.json` 复制到 Skill 目录之外的安全位置。
3. 删除已安装的 `product-material-agent` 文件夹。
4. 删除用户为本 Skill 自行复制且不再需要的 `config.json`；不要删除共享配置。
5. 刷新宿主的 Skills 列表。

卸载不得删除、移动或覆盖客户输入、源素材、生成结果、交付目录、工作日志或宿主账户数据。本包默认不创建远程数据、账号或后台服务，因此没有远程卸载步骤。

## 回滚

1. 备份当前 `config.json`、客户输入和全部工作输出。
2. 对当前包执行上面的卸载步骤。
3. 安装上一份已交付且校验通过的 ZIP。
4. 对照旧版配置结构人工迁移必要设置，不直接覆盖。
5. 运行旧版包内的 `node verify.mjs`，再用合成示例验证。

如果没有上一份已交付版本，保持卸载状态，不从未知来源下载替代包。回滚不会撤回已经由人工发布到外部平台的内容；该操作需由平台负责人另行处理。
