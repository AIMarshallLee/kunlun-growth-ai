# 支持说明

支持入口：<https://skill.kunlungrowth.cn/contact>

## 支持范围

- 安装目录、文件完整性和 `node verify.mjs` 结果；
- `config.json` 的非敏感配置；
- 证据等级、固定输出、阻塞状态和公开合成示例的使用；
- 在已交付版本之间卸载或回滚；
- 可复现的包内文档或合同问题。

响应范围、渠道和时效以有效订单或课程权益记录为准；本文件不单独承诺固定响应时效。

## 提交信息

请提供版本号、宿主名称与版本、操作步骤、实际状态、期望状态和去敏后的错误信息。不得发送 API Key、密码、Cookie、客户原始数据、未授权素材或完整私有配置。

第三方账号、计费、模型可用性、平台审核、客户法务判断和代发布不在默认支持范围内。支持不会要求打开自动联网、上传或发布。
