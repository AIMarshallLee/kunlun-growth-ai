# 公开合成示例

本目录故意不放客户原图、真实订单、真实商品数据或模型输出文件。`synthetic-travel-organizer/` 提供一组成对的输入与预期输出，可直接检查证据分级、固定输出和阻塞规则。

- 输入：`synthetic-travel-organizer/input.md`
- 预期输出：`synthetic-travel-organizer/expected-output.md`

旧的离线演练记录位于 `offline-validation.md`。其中的黑色帆布拉链托特包同样是合成对象，不代表客户、销售或平台审核记录。

公开示例的预期结果不是成品图片或视频，而是：

1. 有来源的英文 Listing 草稿；
2. 主图、拉链细节、表面细节、待授权场景图和待提供替代视角的镜头计划；
3. 不生成视频时的六秒分镜；
4. 标明缺口的交付 Manifest。
