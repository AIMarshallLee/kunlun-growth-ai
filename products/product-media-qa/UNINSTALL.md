# 卸载与回滚

本包不会注册后台服务、修改系统环境变量、自动联网或把客户文件复制到包目录。卸载只处理 Skill 包和用户为本包创建的配置，不处理候选资产、授权参考、报告或其他工作文件。

## 卸载

1. 停止正在使用本 Skill 的任务；
2. 如需保留配置，把 `config.json` 复制到用户选择的安全位置；
3. 从宿主的 Skills 目录删除 `product-media-qa` 文件夹；
4. 刷新宿主的 Skills 列表；
5. 如 `config.json` 另存于外部位置且不再需要，由用户明确选择后单独删除。

不要删除 QA Brief、候选资产、源参考、Asset Inventory、Issue Log 或 Delivery Manifest。它们属于用户工作资料，不属于卸载范围。

## 回滚到已交付版本

1. 记录当前包版本并备份 `config.json` 和正在使用的空白模板副本；
2. 按上述步骤卸载当前包，不移动或覆盖客户输入/输出；
3. 从原始交付记录取得上一份可信 ZIP，核对其版本和发布 SHA-256；
4. 解压到新的 `product-media-qa` 文件夹并运行该版本的 `node verify.mjs`；
5. 对照该版本的 `config.example.json`，只迁移仍兼容的配置值；
6. 用该版本的公开合成示例完成首次运行，再恢复真实任务。

没有上一份可信版本时，执行卸载并通过 `SUPPORT.md` 的入口申请已交付版本；不得从不明来源下载替代包。

卸载或回滚本身不授权删除、修改、上传或发布任何客户资产。
