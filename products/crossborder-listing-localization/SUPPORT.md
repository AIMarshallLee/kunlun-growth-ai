# 支持说明

**支持入口：** https://skill.kunlungrowth.cn/contact

支持资格、响应范围和响应时效以购买记录或课程权益记录为准；本文件不额外承诺固定 SLA。

## 支持范围

- 包完整性、安装、卸载和回滚说明；
- `config.json` 的非敏感配置字段；
- `CONTRACT.md`、模板和公开合成示例的使用；
- 首次运行中可复现的合同结构问题；
- 已交付版本的明确勘误和安全问题。

## 不在支持范围

- 代为持有或配置 API Key、平台账号或客户凭据；
- 提供第三方模型额度、平台审核、法律意见或翻译终审；
- 直接上传、发布或修改线上 Listing；
- 保证排名、转化、销售或其他商业结果；
- 排查未经授权、无法脱敏或未列入支持记录的第三方系统。

## 提交信息

联系时提供产品 slug、包版本、宿主工具名称、操作步骤、实际状态、预期合同状态，以及能够公开的最小错误信息。不要提交 API Key、密码、支付信息、真实订单、个人信息、客户原始资料或未授权商品素材。

如问题涉及客户数据，用合成字段复现。无法安全复现时，只描述文件类型、步骤和失败代码。

## 安全问题

若怀疑包内存在密钥、未声明依赖、越权联网或数据泄露风险，停止使用相关副本，通过支持入口报告产品 slug、版本和不含敏感内容的复现步骤。在获得处理结果前保持 `not_ready`，不要上传或发布相关输出。
