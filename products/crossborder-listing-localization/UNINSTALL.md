# 卸载与回滚

本包不创建远程账号、不自动联网，也不保存远程客户数据。卸载只处理产品包和用户为本包创建的本地配置，不删除客户输入、输出或业务留档。

## 卸载前

1. 确认目标文件夹名称为 `crossborder-listing-localization`；
2. 如需保留设置，把用户创建的 `config.json` 复制到产品文件夹之外的受控位置；
3. 确认客户输入、输出和审核记录存放在产品文件夹之外；
4. 记录当前版本和仍为 `not_ready` 的交付，避免把未完成结果当成已发布版本。

## Codex

从 Codex Skills 目录删除 `crossborder-listing-localization` 文件夹，然后刷新 Skills 列表。不要删除整个 Skills 目录，也不要删除客户工作目录。

## WorkBuddy 或其他兼容宿主

在宿主的 Skill 管理入口移除本包，或只删除该宿主记录的 `crossborder-listing-localization` 文件夹。具体入口以宿主当前说明为准。

## 回滚

1. 备份当前 `config.json` 和产品文件夹之外的工作文件；
2. 卸载当前版本；
3. 安装购买或课程权益记录中上一份已交付 ZIP；
4. 对照旧版本的 `config.example.json`，只迁移仍受支持的设置，不直接覆盖旧版默认配置；
5. 在旧版本目录运行 `node verify.mjs`；
6. 用合成示例完成一次离线运行后，再恢复业务使用。

没有上一份已交付版本时，完成卸载并通过 `SUPPORT.md` 的入口请求处理；不要从未知来源下载替代包。

## 卸载后的数据

用户自行创建的配置备份、客户输入、输出和业务审核记录由用户按自身保留政策处理。本包不会远程删除这些文件。
