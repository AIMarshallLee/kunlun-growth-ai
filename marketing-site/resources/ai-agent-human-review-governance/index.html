治理 / Agent Governance

让 Agent 做准备，
不要替人越权。

企业把 AI 接入内容、销售或交付流程时，风险通常不在“能否生成”，而在于生成后的内容、对象、权限和外部动作有没有被正确确认。人工审核与执行门禁，是让试点可控的基础设施。

先把四件事分开

  1. 草稿：AI 可以整理资料、生成候选方案、形成回复或交付草稿；这不代表内容已经正确或可以外发。
  2. 预检查：检查来源、资料可见范围、目标对象、附件、事实与风险项是否完整；这不等于人工批准。
  3. 人工审核：由明确负责人确认对外口径、对象、渠道、时间和附件，并锁定当前版本。
  4. 最小化执行：只按已批准的对象和范围执行一次动作，并记录结果；范围变化就回到草稿或审核。

哪些动作必须有人确认

发送消息、发布内容、创建外部任务或日程、修改客户可见资料、提交交付文件，以及任何会影响客户、品牌或外部系统的数据写入，都不应因为 AI 已经生成候选内容而自动放行。人工确认需要核对事实、权限、对象、范围、附件和风险。

三条应当直接阻断的规则

  1. 资料来源、可见范围或对外许可不明确时，不使用也不外发。
  2. 没有事实证据却包含客户名称、效果数据、价格、承诺或案例时，停在草稿阶段。
  3. 收件人、账号、平台、附件或定时信息不明确时，不执行外部动作。

从小流程建立治理，而不是一次性上复杂系统

先选一条高频、低风险、可回退的流程，约定谁准备、谁审核、谁执行、如何留存版本和复盘问题。只有当团队已能稳定处理一个小闭环，再讨论更广的自动化、知识库、Agent 或跨工具 Workflow。
